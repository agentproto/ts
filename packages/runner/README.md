# @agentproto/runner

AIP-17 `RUNNER.md` reference implementation. A composable schema block defining the `runner` field — engine (in-process / subprocess / sandbox), optional container image, declarative dependency needs, and resource limits — reused by every manifest format that runs code. Permissions (secrets, network) and IO are defined elsewhere; this block scopes only to the process boundary.

> **Status: 0.1.0-alpha.** Generated by `scripts/scaffold-aip.mjs` — `build()` and `validate()` bodies are TODOs.

Spec: <https://agentproto.sh/docs/aip-17>

## Usage

```ts
import { defineRunner } from "@agentproto/runner"

const x = defineRunner({
  id: "my-runner",
  description: "Short purpose.",
  // ...
})
```
