# @agentproto/skill-pack-agentpush

The `agentpush-plugin` skill pack — source of truth for the skills that teach
an agent to bridge an imported agentpush MCP server (Telegram, WhatsApp,
etc.) with live agentproto sessions — sending outbound messages, binding
contacts to sessions, routing inbound replies back into the same session
instead of spawning a fresh agent every time — and to wire per-service auth
(Bearer/OAuth credentials) through `@agentproto/auth`'s credential broker.

## Editing

The only thing you edit is `src/skills/<slug>/SKILL.md` (+ assets). Never
edit `skills/` or `.claude-plugin/` directly — `pnpm build` generates both
from `src/skills/` + `manifest.json`, using this package's own
`package.json` version (never hand-declared in the manifest).

## Consuming

- **agentproto**: `agentproto install skill/<slug> --pack agentpush-plugin`,
  or once published, the bare npm resolution
  (`agentproto install skill/<slug>` resolves `@agentproto/skill-pack-agentpush`
  automatically).
- **Claude Code / Anthropic**: the versioned bundle + zip built to
  `dist/agentpush-plugin-v<version>.zip` and attached to this package's
  GitHub release — installable directly, without agentproto.

Both are generated by the same `pnpm build`, from the same `src/skills/`.
