# @agentproto/work

AIP-20 `WORK.md` reference implementation. A workspace-only successor to AIP-13 that drops hardcoded project/initiative/task doctypes and delegates all per-item-kind schema work to AIP-18 collections — owning only the work-root manifest (containment rules, status rollups, coordination, saved views) and cross-AIP composition. View mode (`extends` / `appliesTo`) was removed by the AIP-20 redesign.

> **Status: 0.1.0-alpha.** Generated by `scripts/scaffold-aip.mjs` — `build()` and `validate()` bodies are TODOs.

Spec: <https://agentproto.sh/docs/aip-20>

## Usage

```ts
import { defineWork } from "@agentproto/work"

const work = defineWork({
  schema: "work.workspace/v2",
  name: "my-work",
  title: "My work",
  description: "Short purpose.",
  // containment / coordination / views / …
})
```
