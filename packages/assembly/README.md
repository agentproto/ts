# @agentproto/assembly

AIP-24 `ASSEMBLY.md` reference implementation. A workspace AIP for multi-agent collectives. Unifies four collaboration patterns — council (advisory overlay), voting (quorum decision body), peer (network of equals), and hierarchy (reporting tree) — under one doctype, with synthesis rules, locked traits, and audit policy as first-class workspace concerns.

> **Status: 0.1.0-alpha.** Generated by `scripts/scaffold-aip.mjs` — `build()` and `validate()` bodies are TODOs.

Spec: <https://agentproto.sh/docs/aip-24>

## Usage

```ts
import { defineAssembly } from "@agentproto/assembly"

const x = defineAssembly({
  id: "my-assembly",
  description: "Short purpose.",
  // ...
})
```
