# @agentproto/office

AIP-22 `OFFICE.md` reference implementation. A live operating workspace for an organisation — declares which collections (roles, objectives, departments, teams, policies) are tracked, the org-tree containment, reporting hierarchy, and cross-AIP composition with governance, work, knowledge, and agency. Distinct from AIP-6's static company profile (companies.sh community standard).

> **Status: 0.1.0-alpha.** Generated by `scripts/scaffold-aip.mjs` — `build()` and `validate()` bodies are TODOs.

Spec: <https://agentproto.sh/docs/aip-22>

## Usage

```ts
import { defineOffice } from "@agentproto/office"

const x = defineOffice({
  id: "my-office",
  description: "Short purpose.",
  // ...
})
```
