§ 3WALLETSa wallet = a named profile you create

A wallet is a named auth profile — like openrouterPerso — not just "the openrouter provider." Several wallets can back one provider. Each holds a credential (a pasted key or an adopted local login, no stored secret) and an allowlist of models it may run.
