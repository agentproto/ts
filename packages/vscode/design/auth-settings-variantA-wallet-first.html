New wallet — paste a key or adopt a local login. Name it whatever you like (e.g. openrouterWork) — one provider can back several wallets. Fresh install starts here with zero wallets: auth_discover_credentials surfaces logins already on the machine to adopt in one click.
Grounded in list_provider_presets (which providers exist) · auth_profile_summary (each named wallet: id, endpoint, keyStatus, models.mode/ids, and which harnesses currently resolve to it). No secret renders — only last4/fingerprint or the self-refreshing flag.
