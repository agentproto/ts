Grounded in the adapter manifests: each declares the interface it speaks (ANTHROPIC_* vs OPENAI_*), whether it accepts base_url, and routeSelection (free vs derived-from-model). The local router is packages/llm-endpoint — a pack maps a virtual model → a real upstream ({provider, model}) behind the Anthropic /v1/{packId}/messages interface. Native ∪ router-bridge ∪ pack-only is computed, never hand-set.
