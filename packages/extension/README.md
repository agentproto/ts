# @agentproto/extension

AIP-40 `EXTENSION.md` reference implementation. A meta-doctype that lets a workspace declare its own custom doctype as an extension of an existing AIP — adding fields, tightening constraints, **selectively removing non-required parent fields**, **choosing which aspects compose per-aspect** (`inherit: {schema, defaults, parse, path}`), overriding defaults, and choosing a path convention — without going through the public AIP process. The runtime (@agentproto/manifest verbs, MCP server, scaffolder) treats local extensions identically to public AIPs.

> **Status: 0.1.0-alpha.** Generated by `scripts/scaffold-aip.mjs` — `build()` and `validate()` bodies are TODOs.

Spec: <https://agentproto.sh/docs/aip-40>

## Selective composition (v2)

v1 composed the parent wholesale: schema ∪ add_fields, parent defaults
layered, parent parser reused, parent path fallback. v2 adds:

- **`remove_fields`** — drop non-required parent properties. GUARDED:
  a field the parent marks `required[]` refuses removal (mirrors
  AIP-18's "children MUST NOT remove an inherited status"). Hosts pass
  the parent's required list via `opts.parentRequired` — the manifest
  layer's schema is not introspectable from here (same limitation as
  `tighten` verification). Removed fields are *enforced away*: `define`
  rejects inputs carrying them.
- **`inherit`** — per-aspect selection: `{schema, defaults, parse,
  path}`, each defaulting to `true`. Omitted entirely = v1's exact
  wholesale behavior (back-compat is tested). `inherit.parse: false`
  requires a replacement parser in `opts.parse`; `inherit.path: false`
  requires `path_convention`.

```ts
import { specFromExtension } from "@agentproto/extension"

const spec = specFromExtension(ext, {
  parent: appSpec,
  parentRequired: ["id", "description"],
  parse: myParser, // required when inherit.parse is false
})
```

## Usage

```ts
import { defineExtension } from "@agentproto/extension"

const x = defineExtension({
  id: "my-extension",
  description: "Short purpose.",
  // ...
})
```
