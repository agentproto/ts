New package: framework-free MCP Apps host over the official ext-apps AppBridge — transport-agnostic core (`createMcpAppHost`) with pre-ready send queueing and honest host capabilities, plus a browser DOM adapter (`mountMcpApp`) that mounts a `ui://` resource in a sandboxed srcdoc iframe with its CSP.
