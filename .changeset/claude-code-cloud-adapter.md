feat(adapter-claude-code-cloud): new AIP-66 managed cloud agent adapter for Anthropic Claude Code cloud sessions — the first vendor binding of the `cloud:<vendor>` execution target. The vendor owns the machine and the harness (no agentproto daemon runs inside), so the adapter relays rather than runs: first ACP prompt → `claude --cloud "<prompt>"` under a PTY (`node-pty`, answering the first-run folder-trust prompt, 120s cap), later prompts → `claude -p "<text>" --cloud <session id>` (send-only), then polls the undocumented sessions API (`GET /v1/code/sessions/{id}/events`, 2s backing off to 10s) until a NEW vendor `result` event — a turn ends ONLY on the vendor's end-of-turn event (AIP-66 §6), never a timer. Event payloads ARE Claude Code stream-json SDK messages, so the stream-json → ACP mapping reuses `@agentproto/adapter-claude-sdk`'s mappers (assistant text → `agent_message_chunk`, tool_use → `tool_call`, tool_result → `tool_call_update`) — not forked. The `result` event's `total_cost_usd` + `usage` become an ACP `usage_update`; a result without usage emits none (unmeasured, never zero — AIP-66 §7). `session/new` refuses per AIP-66 §3 before any vendor side effect: non-git cwd, dirty tree, missing `origin` remote, unpushed HEAD; and refuses `mcpServers` (§4 backstop; the manifest documents the full refused-field set: sandbox, worktree, commandSandbox, mcpServers, daemonMount, bundles, browser, appServe, inference). `session/cancel` reports unsupported (no vendor interrupt verb). Sessions API client (`src/sessions-api.ts`) takes an injectable fetch + `CredentialSource` (macOS keychain `Claude Code-credentials` → `.claudeAiOauth.accessToken` + org from `~/.claude.json`, or `CLAUDE_CLOUD_OAUTH_TOKEN`/`CLAUDE_CLOUD_ORG_UUID` env), normalizes `session_`/`cse_` ids, round-trips `resume_cursor`, re-reads the credential exactly once on 401 then fails with a `claude auth login` hint — the token is never logged or persisted (§8). Every claude child gets `ANTHROPIC_API_KEY` + the Bedrock/Vertex/Foundry/… redirect toggles scrubbed from its env, and a preflight (`claude auth status`) refuses api_key auth or a logged-out CLI before any side effect. Manifest: slug `claude-code-cloud`, protocol acp, harness label `claude-code`, no model menu (the vendor picks the model); spawned as `node bin/claude-code-cloud-acp.mjs` over stdio JSON-RPC.
