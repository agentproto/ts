Add `@agentproto/voice-elevenlabs`, the ElevenLabs voice provider for `@agentproto/voice`: TTS (HTTP + WebSocket), Scribe file streaming STT and the S2S conversational agent over WebSocket, plus hallucination detection. The package ships its built `dist/` (`files: dist, README.md, LICENSE`), talks to ElevenLabs directly, and registers in the `voice` registry's provider catalog. First npm release: `0.0.0` → `0.1.0` (minor changeset; publish decision owner + second opinion, 2026-11-21).
