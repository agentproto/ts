Enforce AIP-34 node scope on the daemon's read paths. The scope is derived from the calling session's own ground (`desc.cwd`) and operator, never from server config. The spawn digest and every respawn (session restart, lazy resume) project only the caller's node, and a ground the tree cannot place injects nothing. `memory_*` tools pass a `MemoryScope` to the store, so a sealed sibling's items and items above a sealed wall are filtered before pagination and snippets; scoped writes carry the node and operator anchors. `file_*` and `directory_*` tools add node confinement next to root confinement, and `directory_list` filters before paging. `app_data_*`, `app_state_*` and `app_external_*` treat an app inside an invisible node as not installed, and a granted external root inside an invisible node as not granted. `workspace_brain_query` drops hits ingested from sessions outside the caller's projection before the top-K cut. The imported-MCP call guard derives the caller itself and forwards `x-agentproto-caller-session` (and `x-agentproto-caller-node` when the session has a node) as per-call headers to http/sse servers on loopback or with `forwardCaller: true`. A request that names a session the daemon does not know is refused; a request with no caller id stays a host call; a session grounded in no declared tree keeps today's behavior. `registerFsTools`, `registerMemoryTools`, `registerBrainTools`, `registerAppDataTools` and `registerAppExternalTools` take an optional `callerScope`; an external caller that omits it is now refused (fail closed, never served unscoped), and one that wants the old behavior passes `HOST_CALLER`. `CallerScope`, `HOST_CALLER`, `CallerScopes`, `callerScopes` and `CallerRefusedError` are exported from the package root.
