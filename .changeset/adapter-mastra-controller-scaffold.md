New package: scaffold of the AIP-45 proprietary adapter for a Mastra AgentController. Ships the `mastra.agent-controller/v1` manifest schema (zod, with `parseControllerManifest` for frontmatter markdown or plain objects, errors naming the field path) and its generated JSON Schema. The client throws `not implemented yet (E48 PR 2)` until the live controller lands.
